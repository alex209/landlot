# Проверка утверждённой редакции промпта v2

Дата: 6 сентября 2026 года.

Опубликованная версия основного workflow: `579dada8-0b28-4851-bd0a-754028902fdc`.
Предыдущая версия: `1fd1b00d-07f8-4f7f-b677-ae913f110326`.

Полный текст проверенной редакции: [agent-system-prompt-v2.md](agent-system-prompt-v2.md).

## Объём изменений

Внесены только четыре утверждённые пользователем замены:

1. Раздел 2: сохранение всех неизменённых условий, проверка восьми полей перед вызовом инструмента.
2. Раздел 2: явное начало нового поиска, перенос только специально оговорённых прежних условий, уточнение противоречий.
3. Раздел 22: запрет служебного анализа в пользовательском ответе с сохранением полезных объяснений результата.
4. Раздел 11: краткие ответы без обязательного повторения всех условий при каждом уточнении; обязательные предупреждения сохраняются.

Аудит опубликованного workflow подтвердил, что другие параметры узлов, их расположение, связи и настройки не изменены. Память остаётся с окном 10; n8n не перезапускался.

## Методика

Один изолированный тестовый workflow, 10 сценариев, 19 последовательных пользовательских сообщений. Использована та же конфигурация модели и агента, что в основном workflow, с утверждённым промптом. История записывалась в отдельную Simple Memory с уникальным ключом выполнения и сценария; рабочая память VK не использовалась.

Поиск и подсчёт заменены SQL-заглушками: `SELECT` констант без чтения таблиц лотов. Поиск возвращал пустую выдачу, подсчёт — нули. Проверялись фактические аргументы вызовов, а не только текст ответа. Сообщения VK не отправлялись. Это проверка поведения на контролируемых данных, не полноценное сквозное тестирование всех инструментов.

В проверке допускаются дополнительный подсчёт с теми же условиями и вариант фрагмента адреса `серпухов` вместо `серпуховск`. Промпт не запрещает дополнительный подсчёт; оба фрагмента допустимы для заданного теста. Эти случаи не считаются потерей фильтров.

## Сохраняющиеся ограничения

- Запрет служебных рассуждений не обеспечен надёжно: в сценарии противоречивой цены модель вывела разбор правил, а в сценарии адреса — план уточнения перед вопросом.
- Краткость остаётся нестабильной: некоторые ответы повторяют полный набор условий, рассказывают о произведённом изменении и предлагают несколько вариантов расширения поиска. Отсутствие совпадения с проверяемыми фразами не доказывает соответствие всем требованиям стиля.
- В одном ответе о пустой выдаче появилось неподтверждённое обобщение о редкости недорогих участков. Нулевой результат заглушки этого не подтверждает.
- Один прогон не доказывает стабильность модели на произвольных диалогах. Контекст за пределами окна памяти этим изменением не восстанавливается.
- Карточки, геокодер и маршруты в данном прогоне не проверялись; соответствующие разделы промпта и рабочие инструменты не менялись.

В рабочую версию опубликован именно утверждённый текст, без дополнительных несогласованных правил. Следующая редакция для устранения оставшихся проблем требует отдельного согласования. Тестовый workflow не включён в экспорт репозитория.
